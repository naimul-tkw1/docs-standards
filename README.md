# docs-standards

A public collection of Markdown standards for solution and data architecture documentation — conventions, templates, and guidance that anyone can reuse.

## Repository layout

| Folder | Purpose |
|---|---|
| [`standards/`](standards/) | The standards themselves — one Markdown file per standard |
| [`templates/`](templates/) | Ready-to-copy templates that follow the standards |
| [`.github/`](.github/) | Contribution and pull request templates |

## Using these standards

Browse the `standards/` folder, or copy a file from `templates/` into your own project and fill it in. Each standard states its status (Draft, Active, Deprecated) and version at the top.
